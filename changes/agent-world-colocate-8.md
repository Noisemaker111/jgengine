Model loading and drawing live in one `@jgengine/core/model` folder (loaders, model resolution, bounds and collision measurement, merged and instanced models, wind and surface patterns, entity models). The decoder file paths join `assets`; shader warmup, display color, the look and frame diagnostics join `render`; scene capture and the warmup gate join `scene`.
