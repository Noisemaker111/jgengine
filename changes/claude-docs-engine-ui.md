Docs, skill references, tool help and engine doc comments describe UI as what it is now: JSX on the engine's own runtime (`@jgengine/core/ui/jsx`), not React. The perf panel, editor profiler and frame reports name "UI" instead of "React" in their outside-sim breakdown, `perf fps-gap` reports engine UI runtime time as its own "UI runtime" layer, and the README explains that `@jgengine/react` is the engine's UI package despite its npm name.
